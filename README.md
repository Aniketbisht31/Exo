# ExoplanetExplorer 🌌

ExoplanetExplorer is a **Java application** built with **JavaFX** that lets users explore known exoplanets, calculate their **habitability scores**, and analyze planetary data. The app integrates NASA exoplanet data and provides multiple habitability models for scientific exploration.

## Features
- Load exoplanet data from local files or NASA API.
- Compute habitability using multiple models:
  - Simple Habitable Zone (HZ)
  - Earth Similarity Index (ESI)
  - Probability-based model
  - Combined habitability score
- Search and filter exoplanets by name.
- Interactive JavaFX GUI with dark-space theme.
- “About Me” section detailing algorithms and calculations used.
- Dynamic planet table with sorting and selection.
- Educational tool for astronomy enthusiasts.

## Technologies Used
- Java 17+
- JavaFX for GUI
- Gson for JSON parsing
- NASA API for real exoplanet data
- Maven/Gradle (optional) for dependency management
